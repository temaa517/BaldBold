1. ЛОГОТИПЫ ИСПРАВЛЕНЫ
   - Все сломанные логотипы заменены на встроенный SVG
   - Логотип корректно отображается на всех 6 страницах

2. ЦЕНЫ КОНВЕРТИРОВАНЫ В БЕЛОРУССКИЕ РУБЛИ (BYN)
   - Курс: 1 RUB ≈ 0.033 BYN
   - Примеры: 1 890₽→62.37Br, 990₽→32.67Br

3. НАВИГАЦИЯ МЕЖДУ СТРАНИЦАМИ
   - Логотип → Главная страница
   - Каталог → Страница каталога
   - Новинки → Страница каталога

   - Доставка → Главная страница
   - Иконка профиля → Личный кабинет
   - Иконка корзины → Оформление заказа
